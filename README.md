# aiprice

**买 AI 会员之前，先看一眼全网最低价。**

aiprice 把 ChatGPT、Claude、Gemini、Grok 这些主流 AI 服务在各个卡密店铺的在售报价汇总到一张表上，每 1 小时同步一次。同一个会员，不同渠道的价格能差一半，这里把差价和它背后的渠道差异一起摊开。

- 官方卡充、成品号、共享团队位、区域卡分开列，不同质保条款的价格不混在一起比
- 每条报价标注在售状态和库存深度
- 只比价，不卖卡，不收款。交易在店铺自己的网站完成
